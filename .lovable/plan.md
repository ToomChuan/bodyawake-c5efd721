
# 暖康 — 女性身体康复与体态纠正小程序

一个治愈系的移动端 Web App，主打"温柔陪伴 + 动作纠正"。低饱和度鼠尾草绿配色，圆润字体，大圆角卡片，整体风格克制、有呼吸感。

## 设计系统
- **主色**：鼠尾草绿 #A8B89A（核心 CTA、热区高亮）
- **辅色**：莫兰迪粉 #D4A5A5（收藏、呼吸灯）
- **背景**：纯白 + 暖米 #F5F1EA（分区）
- **文字**：深灰 #333（标题）/ #666（正文），不用纯黑
- **卡片**：16–24px 大圆角 + 极淡弥散阴影
- **字体**：圆润无衬线（系统 PingFang / Inter）

## 路由结构（TanStack 多路由 + 底部 Tab Bar）
- `/` 首页
- `/body` 人体图谱
- `/rehab` 康复科普列表
- `/profile` 我的
- `/detail/$id` 部位/动作详情页（共享详情模板）

底部固定 4 个 Tab，圆形线稿图标，激活态填充鼠尾草绿。

## 1. 首页 `/`
- 顶部留白 + 温柔问候："今天身体感觉怎么样？☁️"
- 大圆角轮播卡片（3 张），柔和插画 + 文案
- 金刚区：5 个圆形线稿图标横排（颈 / 肩 / 背 / 腰 / 膝），点击跳详情
- 科普卡片 Feed（用户提供 JSON 渲染）：
  - 标题 `name` + 关键词标签（从 `reason` 提取）
  - 底部用 `""` 引号 + 浅绿底高亮显示 `tip`

## 2. 人体图谱 `/body`
- 顶部胶囊切换"正面 / 背面"
- 中央 AI 生成柔和女性轮廓插画（2 张：正面/背面，用 Lovable AI 图像生成预先生成并存为静态资源）
- 关键部位叠加莫兰迪粉色"呼吸灯"圆点（CSS 动画 pulse）
- 点击热区 → 底部半屏弹窗 (Bottom Sheet)，展示该部位常见问题列表，点击进入详情

## 3. 康复科普列表 `/rehab`
- 顶部双 Tab：「常见疼痛」「动作纠正」
- 列表项：左侧动作示范缩略图（正确/错误对比），右侧标题 + 简短效果描述
- 点击进入详情

## 4. 详情页 `/detail/$id`
- 顶部 1/3 屏 Hero 演示图
- 大圆角白色卡片上滑覆盖，营造层次
- 内容区结构：
  - 大标题 `name`
  - 🔍 成因 `reason`
  - ⚠️ 影响 `effect`
  - ✅ 改善指南 `improve` → 可勾选 Checklist（本地状态）
  - 💚 温馨提示 `tip` → 浅绿圆角框
- 底部悬浮操作栏：左 ❤️ 收藏（粉色），右"开始训练"主按钮（鼠尾草绿）

## 5. 我的 `/profile`
- 顶部温柔默认头像 + 昵称
- 分组卡片列表：
  - 我的收藏（带数量统计）
  - 关于 APP / 使用说明
  - 免责声明
- 收藏空状态：慵懒插画 + "还没有收藏哦，去身体图谱里探索一下吧"

## 6. 首次启动 & 微文案
- 首次打开优雅弹窗：免责声明（"使用前的小叮嘱"），localStorage 记录已读
- 全局微文案口语化、朋友化

## 数据与存储
- 用户提供的 JSON → 放入 `src/data/conditions.json`（请在实施时把 JSON 发给我）
- 收藏 / Checklist 进度 / 免责声明已读 → localStorage（无需后端）
- 人体轮廓插画 → 用 Lovable AI 生成 2 张柔和矢量风格图存为静态资源

## 技术要点
- 5 个独立路由文件，每个 `head()` 配独立 SEO meta
- 底部 Tab Bar 提取为共享组件
- Bottom Sheet 用 Drawer 组件
- 收藏 hook 封装 localStorage 读写
